# Generator feedback — `sandbox/feedback/`

Feedback records from the convergence generator on scenarios or artifacts: quality notes, provenance challenges, requests for re-scoping, or signals that a scenario is (or isn't) converging.

## Rules

- Preserve `scenario_id` and lineage on every record.
- Naming: `F-<scenario_id>-NNN.md`.
- Feedback does not modify scenario records; if a scenario needs correction, the Scout publishes a new versioned scenario record.
